咸鱼喵喵 Wiki · 放到博客上的方法

推荐入口：https://www.serversalem.top/nyaruru-wiki/
资料阅读：https://www.serversalem.top/nyaruru-wiki/guide/index.html

一、用现有网站服务就行

Wiki 是一套静态网页，上传后由浏览器直接运行。WordPress 负责博客文章、导航和介绍；现有 Nginx 负责把 Wiki 的 HTML、脚本、样式和图片发给访客。
不需要另开一个 Nginx、端口、容器、数据库或 Node.js 常驻服务。生成资料页需要本机 Node.js，访客和服务器不需要运行生成器。

建议放在博客同域名的 /nyaruru-wiki/ 子目录。博客和 Wiki 都使用 www.serversalem.top，访客可以直接打开完整页面，文章里也可以嵌入展示。

二、上传文件

1. 在主机面板中找到 www.serversalem.top 当前的网站根目录。通常可以看到 wp-admin、wp-content、wp-includes 和 index.php。
2. 在这个根目录内新建 nyaruru-wiki 文件夹。
3. 把本项目 dist 内的全部文件及子目录上传进去。最终层级应当是：

   网站根目录/
     index.php
     wp-admin/
     wp-content/
     nyaruru-wiki/
       index.html
       app.js
       styles.css
       data.js 及其他资料脚本
       assets/
       guide/

不要再套一层 dist，不要覆盖博客根目录的 index.php。上传现成的站点压缩包时，先确认压缩包根部直接是 index.html、assets/、guide/ 等文件。

如果从 GitHub 下载源码压缩包，解压后只上传其中 dist 内的内容；scripts、说明文档和项目根目录的其他文件留在本机即可。

当前 site.config.json 已按推荐地址设置，资料页也已生成。只有实际部署目录或域名变化时，才需要修改 siteUrl 并在本机重新运行：

   node scripts/build-guides.js

三、先直接打开 Wiki

上传完先访问：https://www.serversalem.top/nyaruru-wiki/
再访问：https://www.serversalem.top/nyaruru-wiki/guide/index.html

正常情况下，现有网站配置就能提供这些文件。先确认地图、物品图标、人物与剧情、关于都显示正常，再往 WordPress 放入口。

如果已有目录仍被 WordPress 接管，或目录地址找不到 index.html，可以在现有 www.serversalem.top 的 Nginx server 配置块内补充以下 location。它继承这个站点已有的 root，不需要另写服务器路径：

   location ^~ /nyaruru-wiki/ {
       index index.html;
       try_files $uri $uri/ =404;
   }

这段只用于网站根目录里确实存在 nyaruru-wiki 文件夹的情况。保留原有 WordPress 和 PHP 配置，先用主机面板检测配置，通过后再重载 Nginx。

四、在 WordPress 放入口或嵌入

最推荐：在博客菜单或一篇介绍文章里放“打开咸鱼喵喵 Wiki”按钮，链接到 /nyaruru-wiki/。完整地图有更充足的宽度，手机上也更好操作。

如果想在博客文章里直接展示 Wiki，就添加“自定义 HTML”区块，粘贴同目录 WordPress自定义HTML示例.html 的内容。它使用 iframe，也就是在文章里放一扇打开 Wiki 的窗口。
Wiki 文件仍由 /nyaruru-wiki/ 提供，iframe 不会代替上传文件。保留示例中的“独立打开”入口；主题能选择全宽或关闭侧栏时，可以使用这些选项。

不要把整份 index.html 和所有脚本、样式直接粘进 WordPress 编辑器，也不要通过媒体库上传这些程序文件。

如果保存后 iframe 被删除，检查账户权限和相关插件的嵌入设置；如果提示拒绝连接，检查本站是否允许同源嵌入。也可以直接使用上面的普通链接入口。

五、让搜索引擎找到资料页

资料页有各自独立的网址，点地图、结局或完整人物档案时会进入完整版的对应位置。
博客介绍文章可以链接资料首页，也可以直接链接某个物品或剧情资料页。

WordPress 的站点地图通常不会自动收录这个独立目录。可以在 Google Search Console、必应站长工具等后台另外提交：

   https://www.serversalem.top/nyaruru-wiki/guide/sitemap.xml

同域名目录方便博客与 Wiki 相互链接，不保证搜索排名会自动提升。

首页搜索结果的标题与摘要

首页标题为“咸鱼喵喵百科｜地图、物品、人物与成就攻略”，首屏展示百科介绍，网页说明保留百科的功能与非官方性质。首页的统一收录地址（canonical）是 https://www.serversalem.top/nyaruru-wiki/，带 index.html 的地址也指向这个地址。
清单保存说明使用 data-nosnippet 标记：Google 支持用它排除这部分摘要文字，页面上仍可正常阅读；其他搜索引擎是否支持，以各自规则为准。

这次修改需要同步上传 dist/index.html 和 dist/app.js 到服务器的 nyaruru-wiki/ 目录，并清理这两个文件对应的网站或 CDN 缓存（如有）。只更新 HTML 会留下旧脚本改写标题的问题。
上传后，直接打开 /nyaruru-wiki/，确认首页介绍和浏览器标签标题已更新。再切换到“关于”并返回“世界地图”，确认标题仍正确。
在 Google Search Console 的“网址检查”中检查 https://www.serversalem.top/nyaruru-wiki/ 并请求编入索引；必应站长工具可提交同一网址。若后台尚未验证网站所有权，需要先完成验证。
搜索结果要等搜索引擎重新抓取和处理后才可能更新；它仍可能根据搜索词改写标题或从其他正文生成摘要，不能保证逐字采用网页说明。
以后更改域名或部署目录时，除 site.config.json 和生成资料页外，也要同步修改 dist/index.html 的 canonical。

六、以后更新

保留完整项目作为维护源。资料、模板或样式变化后，按需要重新生成资料页，在本机检查，再更新服务器上 nyaruru-wiki 目录的文件。
上传时保留目录结构，避免新旧脚本混用。如果界面仍显示旧内容，清理对应网页的浏览器和网站静态缓存，再刷新查看。

保留“关于”、条目来源和许可说明。相关摘编文字遵循 CC BY-NC-SA 4.0，游戏图片的权利不随文字协议一并开放。
收集清单保存在访客浏览器，所选存档和成就缓存也只在浏览器处理；网站不需要增加上传存档的后端接口。
